## 目的

A1 默认关闭后，candidate 与 baseline 的 ASR 文本差异只剩 A3（`condition_on_previous_text=False`）。A5 只增加置信度字段，不改变文本。用同一 WAV 测 A3 的净效果。

| 指标 | baseline | candidate（A3 on，无 A1） |
| --- | ---: | ---: |

| 胜负 | — | 2 胜 / 5 负 / 2 平 |

A3 没有净收益，略差 +0.0032。

## A3 off 验证

把 worker 的 `condition_on_previous_text` 恢复默认（不设置该字段），decoder 版本升到 5。用 `BV1KjoxBoEQJ` 180–240s 做一次 spot check（candidate 另抽 WAV，baseline 取 M3 日志，不是严格同一 WAV 配对）：

| 版本 | CER | 段数 |
| --- | ---: | ---: |
| baseline（M3 日志） | 0.1429 | 23 |
| candidate（A3 off，另抽 WAV） | **0.1429** | 23 |

这次 spot check 后，又做了 8 个同 WAV 配对（每个窗口先抽一次 WAV，两臂复用）：**8/8 的 CER 与段数逐项完全相等**，详见 [`a3off-pairs-20261120.md`](a3off-pairs-20261120.md)。结果与 A3 是此前差异来源的假设一致；恢复默认后两臂 CER/段数逐项相等，但没有逐字比对，不能宣称完全等价。`BV161nZ6JE6b` 60s 因 WAV 准备失败未计入。

## 结论

- A3 不默认启用；代码恢复 baseline 的默认上文条件。8 个同 WAV 配对 CER/段数逐项相等（1 个窗口未计入），但未逐字比对，不能宣称完全等价。
- A1 hotwords/metadata prompt 默认关闭；只保留 A5 的 `lowConfidence` 元数据。
- 因此 research 分支的 ASR 部分不再声称文本精度提升；剩余价值是 P2 低码率音轨、缓存 key 修复和置信度标注。
- A5 的低置信阈值需要单独用人工标注校准，当前只能作为提示，不能当事实。
