## 汇总

9 个有效配对：

- baseline 均值 **0.1486**
- candidate 均值 **0.1528**
- 差值 **+0.0042**（candidate 略差，约 +2.8%）
- 3 胜 / 5 负 / 1 平

## 结论

- A1 的 **hotwords 必须禁用**（已修）；candidate（metadata prompt + A3/A5）在 held-out 上没有净收益，因此 `asrHints()` 默认返回空，只保留 daemon 内置简体引导句；metadata prompt 仅作为显式 opt-in 保留，decoder 版本升到 4。
- **A1 没有被单独隔离**：这轮差异包含 A1 + A3（`condition_on_previous_text=False`）+ A5（置信度标注）。0.0042 的差值不能全部归因于 metadata prompt；默认关闭是保守选择，但 prompt 的净效果还需要在同一个 decoder 上做 prompt on/off 复测。
- 样本仍是 smoke 级：AI 字幕参考、6 个 AI 主题视频、边界 cue 未对齐；两个 arm 独立拉取字幕，track/长度一致但不能证明是严格同一快照。不能据此宣称阶段 2 有效或无效。
